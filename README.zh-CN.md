# Dexter's Laboratory V1

基于 Lattice 的本地研究工作空间。

从问题出发，完成问题定义、文献与已有知识搜索、思维导图、环境与基线验证、
实验设计、执行、结果验证和分析，并在 `main.tex` 中维护研究记录。

这是 V1 源码准备版本，不包含私人研究、聊天记录、账户凭据或预编译运行时。
新的研究项目使用空白模板。模型服务和 LaTeX 工具需要在本地配置。

完整功能、开发步骤、限制和许可证说明请见 [English README](README.md)、
[CONTRIBUTING.md](CONTRIBUTING.md) 和 [NOTICE](NOTICE)。
